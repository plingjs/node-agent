# 入门者学习指南

这门课面向会写基础 JavaScript、但还没做过 Agent 的 Node.js 开发者。你需要认识变量、函数、对象、数组、Promise、`async/await`、ES Modules，并会在终端切换目录、运行命令。课程不要求先学机器学习。

## 第一次运行

先确认 Node.js 版本为 18 或更高：

```bash
node --version
```

每章都是独立目录，代码从该章开始运行。以第一章为例：

```bash
cd lesson01-minimal-agent
npm test
```

章节测试使用假模型或本地替身，不需要 API key，也不会调用真实模型。想和模型对话时，再按该章 README 配置兼容 OpenAI Chat Completions 的模型服务，然后运行：

```bash
node main.js
```

不要把 API key 写进代码或提交到仓库。运行失败时，先检查当前目录、Node 版本和该章 README 中的配置项。

## 每章按这个顺序学

1. **先看运行结果。** 先运行章节 README 中的离线命令，确认项目能启动，再看教程里的预期输出。
2. **带着一个问题读代码。** 先找到入口文件，再顺着调用关系读两三个关键文件，不必一开始读完整个目录。
3. **跟踪一条数据。** 对 Agent 来说，最有用的线索通常是 `messages`：看用户输入怎样进入数组、模型怎样返回 `tool_calls`、工具结果怎样以 `role: "tool"` 写回去。
4. **观察一次失败。** 参数不合法、工具不存在或模型服务不可用时，看看错误在哪里被接住，又怎样回到用户或模型。
5. **完成本章练习。** 练习应能离线完成。先按验收标准检查结果，再看章节中的延伸说明。

章节里会出现较长的文件地图和参考资料。第一次学习时，优先看“这一章解决什么”“先运行”“主流程”和“动手练习”；面试题、完整测试清单和实现边界可以留到第二遍。

## 13 章路线

| 章节 | 你要回答的问题 | 重点代码 |
|---|---|---|
| 1 最小循环 | 模型怎样要求程序调用工具？ | `agent.js`、`tools.js` |
| 2 工具系统 | 怎样校验参数、处理错误和确认权限？ | `registry_full.js`、`validation.js` |
| 3 上下文 | 对话变长后怎样控制发给模型的内容？ | `context_manager_v2.js` |
| 4 核心工具 | 怎样让 Agent 读写文件、搜索和运行命令？ | `tools/`、`core_tools.js` |
| 5 记忆 | 怎样保存长期信息，并只取回相关内容？ | `memory_manager.js`、`recall.js` |
| 6 多 Agent | 怎样把独立子任务交给另一个 Agent？ | `agent_tool.js`、`subagent.js` |
| 7 Skill | 怎样按任务加载说明和工作步骤？ | `skill_registry.js`、`skill_trigger.js` |
| 8 Plugin | 怎样在工具执行前后运行额外逻辑？ | `hooks/`、`plugins/` |
| 9 MCP | 怎样发现并调用另一个进程提供的工具？ | `mcp/` |
| 10 会话 | 怎样保存、恢复和切换对话？ | `session_state.js`、`session_manager.js` |
| 11 网关 | 怎样把终端或 QQ 消息接到 Agent？ | `gateway/`、`agent_bridge.js` |
| 12 定时任务 | 怎样在设定时间触发一次 Agent 运行？ | `cron/` |
| 13 可靠性 | 怎样处理重试、流式输出、观测和评测？ | `llm_retry.js`、`streaming.js`、`telemetry.js` |

建议按顺序学习。第 1–4 章建立主循环和工具调用概念；第 5–9 章扩展 Agent 的记忆和能力；第 10–13 章处理保存、接入和运行问题。遇到不熟悉的语法，先查对应文件的调用位置，不必把所有章节一次读完。

## 常用词

| 词 | 在本课程里的意思 |
|---|---|
| Agent | 会反复调用模型、执行工具并把结果送回模型的程序。 |
| LLM | 大语言模型。它接收消息并生成回复或工具调用请求。 |
| `messages` | 发给模型的消息数组，包含用户、助手和工具消息。 |
| `tool_calls` | 模型提出的工具调用请求；程序还要自己找到函数并执行。 |
| `role: "tool"` | 程序执行工具后，把结果按对应调用 ID 写回消息数组。 |
| 上下文 | 当前一次模型请求能看到的消息和系统说明；它受模型窗口长度限制。 |
| token | 模型处理文本时使用的计量单位；它不等同于字符数。 |
| 会话 | 一段可保存和恢复的对话状态。记忆则是从对话中提取、以后可能复用的信息。 |
| Skill / Plugin / MCP | Skill 提供任务说明；Plugin 在程序生命周期中挂钩；MCP 用协议连接外部工具服务。 |

## 遇到问题时

- `npm test` 报找不到文件：先确认终端当前目录是某个 `lesson...` 目录。
- 真实模型返回 401：核对 API key、服务地址和模型名；不同章节的配置方式可能不同，以该章 README 为准。
- 模型没有调用工具：检查工具说明和模型是否支持工具调用；先用章节里的假模型用例区分代码问题与服务配置问题。
- 程序看起来没退出：留意该章是否启动了定时器、服务器或网关；这类资源需要显式关闭。

课程代码用于学习设计与实现。章节中写明的简化项要按其边界理解；文件系统、Shell、网络访问和多用户接入在真实业务里还需要额外的隔离、授权和运维设计。
